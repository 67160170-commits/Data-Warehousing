# AI Demand Forecasting Dashboard (Business Idea Creation, Week 11)

Dashboard เชิงเล่าเรื่องสำหรับโปรเจกต์ **AI Demand Forecasting & Supply Chain Management** ในโรงงานผลิตภัณฑ์ชีวภาพ
เล่าตามลำดับ: ความต้องการโตขึ้น → ทดสอบว่า AI แม่นกว่าวิธีเดิม → แปลงเป็นวัตถุดิบที่ต้องใช้ → สิ่งที่ผู้จัดการควรสั่ง

> ข้อมูลทั้งหมดเป็นข้อมูลจำลอง (seed คงที่) เพื่อสาธิตแนวคิด ไม่ใช่ข้อมูลจริงของบริษัท

## โครงสร้าง
| ไฟล์ | หน้าที่ |
|---|---|
| `data/demand_history.csv` | ยอดสั่งซื้อรายเดือน 24 เดือน x 3 ผลิตภัณฑ์ |
| `data/demand_forecast.csv` | ค่าพยากรณ์ 6 เดือนข้างหน้า พร้อมช่วงความไม่แน่นอน |
| `data/bom.csv` | วัตถุดิบต่อหน่วยสินค้า (kg/หน่วย) |
| `data/material_plan.csv` | ความต้องการวัตถุดิบ สต็อก สถานะ และปริมาณที่แนะนำให้สั่ง |
| `scripts/build.py` | สร้างข้อมูล ฝึกโมเดล แล้วฝังผลลงใน dashboard |
| `dashboard/template.html` | ต้นฉบับหน้า dashboard |
| `dashboard/index.html` | หน้าที่ build แล้ว เปิดในเบราว์เซอร์ได้เลย |

## วิธีรัน
```bash
python scripts/build.py      # ใช้ Python มาตรฐาน ไม่ต้องติดตั้งไลบรารี
open dashboard/index.html
```

## วิธีคิดของโมเดล
เส้นแนวโน้ม (least squares) x ดัชนีฤดูกาลรายเดือน เทียบกับวิธีเดิม "เฉลี่ย 3 เดือนล่าสุด"
ทดสอบแบบ rolling ล่วงหน้า 1 เดือน ย้อนหลัง 6 เดือน วัดด้วย MAPE
วัตถุดิบที่ควรสั่ง = ความต้องการ 2 เดือนข้างหน้า x 1.15 (safety stock) - สต็อกคงเหลือ

## ต่อยอดได้
เปลี่ยนข้อมูลจำลองเป็นยอดสั่งซื้อจริง, ใช้โมเดลอื่น (Prophet, XGBoost), เพิ่ม lead time ของผู้ขายแต่ละราย
